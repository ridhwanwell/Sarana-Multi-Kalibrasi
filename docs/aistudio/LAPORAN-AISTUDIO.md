# LAPORAN KERJA AI STUDIO — Tera SMK
Diisi AI Studio setiap selesai satu langkah (lihat `docs/aistudio/PRD-AISTUDIO.md` bagian 5). Dibaca Claude saat audit.

Format tiap entri:
```
## <tanggal> · <langkah, mis. A1>
- File dibuat: …
- File lama diubah (+ alasan): …
- Uji: <nama uji> <lulus>/<total>; uji lama: …  (tulis "belum dijalankan" bila belum)
- SQL ditulis (BELUM DIJALANKAN): …
- Keputusan yang diambil sendiri: …
- PERLU KONFIRMASI RIDHWAN: …
- Teks sertifikat baru (PERLU PERSETUJUAN): …
```
